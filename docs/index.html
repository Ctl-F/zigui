zigui

zigui is a retained-mode, cross-platform UI toolkit for Zig 0.17, built for IDEs, text editors, and paint programs. You build a tree of nodes once, change what changes, and the toolkit lays out, paints, and redraws only the damaged parts.

What is in the box

  • Core: node tree, flex layout (with wrap and absolute positioning) and grid layout, events with capture/target/bubble, focus scopes, commands and scoped shortcuts, damage-tracked painting.
  • Widgets: Label, Button, TextField, CodeEditor, FindBar, Popup, Completion, Hover and signature help, Terminal, Canvas, ScrollView, SplitView, TreeView, Select, TabPanel, Dock, and menus (popup, context, menu bar).
  • Rendering: a software rasterizer and an SDL3 GPU backend behind one Backend interface.
  • Tooling: a runtime widget schema, generated forms and wizards, ZON UI documents, and a visual builder.
These docs are a living document. Every new feature and widget must be documented here in the same change that adds it; see Maintaining these docs.

Conventions used in the examples

  • zigui means const zigui = @import("zigui");. Examples assume ui is your Ui value (pass &ui where a *Ui is wanted), gpa: std.mem.Allocator, and app for your own state struct.
  • Callbacks are written .bind(&app, App.method), where method is fn (*App, *zigui.event.Event) void.
  • Snippets are trimmed for reading. examples/ holds complete programs that compile: dedit.zig (smallest), demo.zig, paint.zig, builder.zig, workbench.zig.
