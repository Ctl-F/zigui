Documentation search

Edit > Search Documentation... (Ctrl+Shift+D) finds functions and types by describing what you want: type path from dir, read file into memory or compare two strings. It looks through the project and the Zig standard library and shows each match with its kind, file and line, and its signature (or the first words of its doc comment). Enter opens the source at the declaration. The last row is always Search the web for "...": it opens https://www.google.com/search?q=zig+YOUR+WORDS in the default browser (the word zig is added to the search).

How the ranking works

It is ranking by words, not by meaning:

  • The query is split into words; small words (from, the, how, get...) and one- or two-letter words are ignored.
  • Names are split into words at case changes and underscores (readFileAlloc is read, File, Alloc); a query word matches a whole word (a plural counts), or the start of one (dir finds directory).
  • Name hits count most, then words in the /// doc comment, then the words of the file's own path (std/fs/path.zig). A name made of many words counts a little less for each word.
  • Matching more of the query's words ranks higher; a doc comment that mentions all of them gets a bonus. Declarations holding every word are scored first, and ones with only some are added only when there are few.
  • Project declarations rank above library ones on ties.

So it finds what is written down in the names and comments. It does not know synonyms: parent folder will not find a function documented as "the directory component". When the answer is not in the list, the web row is one Enter away.

Under the hood

The Ctrl+, index (ide.symbol_index.SymbolIndex) also keeps each declaration's doc comment (about 240 bytes), a function's one-line signature and a lowercase text used to skip non-matches quickly. ide.doc_search.rank(lists, query, out) and webSearchUrl are UI-free; ide.doc_search.DocSearch is the box, built on QuickPick's new external mode (the owner ranks: Options.external and on_query; see the widget page). The web row calls a hook; the IDE app opens the browser with sdl.openUrl (SDL's SDL_OpenURL). Headless: cmd project.search_docs (a scripted run only logs the address it would open).
