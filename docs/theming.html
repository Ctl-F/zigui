Theming

Widgets get their look from ui.theme (type zigui.Theme): colors, metrics, and one painter per widget type. A painter draws the widget's box; behavior never changes with the theme.

Theme fields

FieldMeaning
button_colorsFour sets (normal, primary, danger, flat) of normal/hover/pressed/disabled colors; the button's variant picks the set.
field, editorColors for text fields and code editors (background, border, text, selection, caret, syntax colors).
corner_radiusRounded-corner radius for buttons and fields (default 6).
button_padding, field_paddingInner spacing applied to buttons and text fields whose style has no padding of its own, so rounded corners stay clear of the text. Set an explicit style.padding on a widget to override.
focus_ring, focus_ring_widthKeyboard focus ring.
ui_font, mono_fontFont ids from ui.addFont. Both default to 0; set mono_font when you add a monospace font.
font_size, text_colorDefault text size (14) and color.
button_painter, label_painterPainter functions (see below).

Changing the theme

var theme = ui.theme;
theme.corner_radius = 3;
theme.button_padding = zigui.style.Edges.xy(16, 6);
theme.text_color = zigui.Color.rgb(230, 230, 230);
ui.setTheme(theme);          // marks everything for relayout and repaint

Per-widget overrides

Buttons and fields accept colors in their options (and props.colors at runtime) to override the theme for one widget:

b.props.colors = .{ .normal = red, .hover = red, .pressed = red, .disabled = red, .border = zigui.Color.white, .border_width = 1 };

Custom painters

A painter is fn (ctx: *PaintCtx, b: *const Button) PaintCtx.Error!void. Draw the box with ctx.box(visual) or raw draw-list calls on ctx.list inside ctx.rect; set ctx.text_color to recolor the label.

fn flatPainter(ctx: *zigui.PaintCtx, b: *const zigui.Button) zigui.paint_ctx.Error!void {
    try ctx.box(.{ .background = if (b.out.hovered) hover_color else base_color, .radius = 2 });
}

var theme = ui.theme;
theme.button_painter = flatPainter;     // every button
ui.setTheme(theme);
button.setPainter(flatPainter);         // or just this one
