Settings, key bindings and sessions (in the IDE)

Settings

File > Settings opens .zigide/settings.zon in the editor (creating it from a commented template if it is missing). Save the file and the IDE applies it at once. Two files are layered, the project's overriding yours:

  • $XDG_CONFIG_HOME/zigui-ide/settings.zon (or ~/.config/zigui-ide/settings.zon): yours, for every project. Edit it by hand.
  • <project>/.zigide/settings.zon: this project's (commit it to share it).
KeyDefaultMeaning
.ui_font_size0Interface text size in logical pixels; 0 keeps the theme's. Applied live.
.editor_font_size0Source editors' text size; 0 keeps the theme's. Applied live to open editors.
.tab_width41–16. Applied live.
.line_numbers, .foldingtrueGutter and fold arrows. Applied live.
.restore_sessiontrueReopen the last session's files and panel layout at startup.
.language_server""The Zig language server command; "" means ZIGUI_ZLS or zls. Read at startup.
.shell""The terminal's shell; "" means $SHELL. Read at startup.

Unknown keys and values of the wrong type are ignored (the status line says how many), so a typo never stops the IDE from starting.

Key bindings

File > Keyboard Shortcuts File opens .zigide/keybindings.keymap, created with the IDE's default bindings listed as comments. One binding per line:

ctrl+shift+q = file.quit          # chord = command
ctrl+k ctrl+c = edit.comment      # a sequence of chords
f5 = none                         # remove a binding

Saving applies it. Lines override the defaults (and ~/.config/zigui-ide/keybindings.keymap, read first); removing a line takes effect after a restart. Command names are the ones in the menus' source (file.save, edit.find, ide.build, view.terminal, refactor.rename_handler, ...). The format is Shortcuts.loadKeymap; mod is Ctrl (Cmd on macOS).

Session and panel layout

When the IDE quits or restarts it writes .zigide/session.zon: the open files with the caret in each, the active tab, the UI document being designed, and the arrangement of every panel (which are tabs of which group, the splits and their sizes, floating windows, hidden panels). The next start reopens it (with .restore_session = false it does not; files named on the command line with --open take its place). Files that are gone are skipped; panels that appeared since are kept visible. The file is safe to delete. View > Reset Panel Layout goes back to the arrangement the IDE starts with.

For your own program

  • Dock.saveLayout(gpa) returns the arrangement as ZON text, panels named by title (a trailing " •" modified marker is ignored); Dock.loadLayout(text) applies it: panels are matched by title, unknown names are skipped, a split with one side unknown collapses to the other, and a panel that was showing but is in neither list stays visible as a tab of the first group. error.InvalidLayout for text that is not ZON.
  • ide.session: save, load and Session.restore. ide.settings: Settings.apply, load, template, keymapTemplate.
  • Documents.defaults / applyDefaults() set up new and open editors; Documents.on_saved is called after a save; CodeEditor.configure(size, tab_width, line_numbers, folding) changes a live editor.

Headless runs (ZIGUI_SCREENSHOT) neither read nor write the session unless ZIGUI_SESSION=1.
