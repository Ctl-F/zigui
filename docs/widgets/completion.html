Completion

A suggestion list that follows typing in a CodeEditor, shown in a focus-less popup. It asks providers for candidates and ranks them against the word before the caret.

const comp = try zigui.completion.Completion.create(&ui);
defer comp.destroy();
try comp.addProvider(.bind(&mine, Mine.complete));   // optional
try comp.attach(editor);                              // for each editor
// before destroying an editor: comp.detach(editor);

What the user sees

Do thisResult
Type an identifier (two letters), or .The list opens below the word.
Ctrl+SpaceOpens the list even for an empty word.
Keep typing / BackspaceThe list narrows (it closes when nothing matches or the caret leaves the word).
Up, Down, PageUp, PageDownMove the selection (wraps).
Enter or Tab, or a click on a rowReplaces the word with the item's text and puts the caret after it, as one undo step.
Escape, Left/Right/Home/End, a click in the text, or leaving the editorCloses the list.

Providers

A provider is fn (ctx, *const Request, *Sink) void (Provider.bind(&x, X.complete)). It is called on every keystroke while a list is possible, so it must be quick (look things up; do not scan files). Request has editor, prefix (the word before the caret), word_start (byte offset), line_before (the line's text before the word), explicit (Ctrl+Space) and afterDot(). Sink.add(.{ .label, .insert, .detail, .tag }) copies its strings; insert defaults to the label.

The built-in words source (on by default; comp.words = false to turn off) offers identifiers already in the buffer (files over 1 MiB are skipped), so every language gets something with no setup. A provider that works in the background (a language server) calls comp.offer(editor, word_start, items) when its answer arrives; it is ignored if the caret has left that word.

Ranking

Exact prefix first, then prefix ignoring case, then letters in order (gtl finds getTotalLength); ties go to the shorter label, then alphabetical. Duplicates collapse and at most 200 rows are shown.

Editor hooks it uses

CodeEditor hook lists (addKeyHook, addEditHook, removeHooks; see the editor page), plus replaceRange(start, end, text), language() and caretRect(). Attaching a Completion adds one key hook and one edit hook; hover and signature help add their own beside it.

Zig, offline

The IDE's ide.zig_complete.ZigCompleter is a provider that reads the standard library and your files with std.zig.Ast; see the IDE page.
