FindBar

Find and replace for a CodeEditor. It is a small hidden panel you place (usually just above the editor); attach it and Ctrl+F in the editor opens it, Ctrl+H opens it with the replace row.

const find = try ui.add(zigui.FindBar, column, .{});
find.attach(editor);
Do thisResult
Type in the Find fieldEvery match is highlighted in the editor (the current one stronger), the first one at or after the caret is selected, and the count shows ("3 of 12", "No results").
Enter / Shift+Enter, Next / PrevStep through the matches, wrapping around.
Aa and W togglesMatch case; whole word only (a match may not touch a letter, digit or underscore).
Replace (or Enter in the Replace field)Replace the current match and move on.
Replace allReplace every match as one undo step.
Escape or the × buttonClose the bar, remove the highlights and focus the editor again.

If the text changes while the bar is open (typing, undo), the matches are recomputed. A one-line selection seeds the query when the bar opens.

API

  • attach(editor), show(replace), hide().
  • findNext(), findPrev(), replaceCurrent(), replaceAll() usize, refresh(select).
  • props: case_sensitive, whole_word, show_replace. out: match_count, current (1-based, 0 for none), open.

The search engine

zigui.search (editor/search.zig) is the matcher it uses, with no UI: indexIn(haystack, needle, from, opts), findAll(doc, gpa, query, opts, max) (line by line, so a huge document is never copied; a query containing a newline copies the text once), nextIndex and prevIndex. Project-wide search will run it over files on worker threads.

Limits

Literal matching only (no regular expressions yet), at most 10,000 highlighted matches, and the bar is code-only (it needs an editor to attach to, so it is not a toolbox widget).
