CodeEditor

A multi-line editor for source code: line numbers, incremental syntax highlighting, undo/redo, multiple cursors, large-file support (only visible lines are shaped and drawn).

const ed = try ui.add(zigui.CodeEditor, parent, .{
    .style = .{ .grow = 1 },
    .language = &zigui.syntax.zig,
    .on_change = .bind(&app, App.textChanged),
});
try ed.loadText(source_bytes, false);    // false: borrowed; true: the editor takes ownership of an allocation
ui.setFocus(ed.node);

Methods

MethodPurpose
loadText(bytes, owned) !voidReplace the whole content (resets undo).
textAlloc(gpa) ![]u8Copy the content out; you free it.
openFile(io, path) !voidMemory-map a file; line indexing runs incrementally so huge files open at once.
markSaved()Reset out.modified after saving.
setLanguage(?*const Language) !voidChange highlighting.
core() *EditorThe editing engine (selections, edits, undo) for scripted changes.
caretRect()Caret position, for IME placement.

Keys

Typing; Enter keeps indentation; Tab/Shift+Tab; Backspace/Delete (Ctrl or Alt for words); arrows, Home/End (Ctrl for document), PageUp/Down; Shift extends the selection; Ctrl+A/C/X/V; Ctrl+Z, Ctrl+Y, Ctrl+Shift+Z; click and drag, double-click selects a word, triple-click a line; Alt+click or Ctrl+Alt+Up/Down adds cursors; Esc drops extra cursors.

Example: a save flow

fn save(self: *App) !void {
    const text = try self.editor.textAlloc(self.gpa);
    defer self.gpa.free(text);
    try std.Io.Dir.cwd().writeFile(self.io, .{ .sub_path = self.path, .data = text });
    self.editor.markSaved();
}
