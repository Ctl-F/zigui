CodeEditor

A multi-line editor for source code: line numbers, incremental syntax highlighting, undo/redo, multiple cursors, large-file support (only visible lines are shaped and drawn).

const ed = try ui.add(zigui.CodeEditor, parent, .{
    .style = .{ .grow = 1 },
    .language = &zigui.syntax.zig,
    .on_change = .bind(&app, App.textChanged),
});
try ed.loadText(source_bytes, false);    // false: borrowed; true: the editor takes ownership of an allocation
ui.setFocus(ed.node);

Code folding

With folding = true the gutter gets an arrow column: click the arrow of a line that has more deeply indented lines under it to hide those lines (a folded line shows ··· after its text and an arrow pointing right); click again to open. Ctrl+Shift+[ folds the region at the caret, Ctrl+Shift+] opens it. Regions come from indentation (blank lines inside belong to the region). Folded lines are skipped by the arrow keys, counted as one row for scrolling and hit testing, and opened when you edit them or move the caret into them; a fold below an edit moves with it, and one the edit touches opens. The painter, scrollbar and caret all work in display rows.

Language-aware folding (brace matching, a language server's ranges) is planned; the model is just a list of line ranges.

Decorations

Hosts mark byte ranges with a look: setDecorations(owner, items) (sorted by start; owner is 0–7, one set per feature: the find bar uses 0) and clearDecorations(owner). Kinds: .highlight and .current (tinted backgrounds), .error_squiggle, .warning_squiggle, .info_squiggle (underlines). Colors are find_match, find_current and squiggle_* in the editor colors. Decorations follow edits: ranges after an edit shift, and a range whose text is deleted shrinks or disappears. selectRange(start, end) selects and scrolls to a range. goTo(line, col) (1-based, column in bytes, clamped) moves the caret and scrolls it into view, centering it when it was off screen.

Keys

Typing; Enter keeps indentation; Tab/Shift+Tab; Backspace/Delete (Ctrl or Alt for words; Backspace in leading spaces erases back to the previous tab stop, so one press undoes one indent step); arrows, Home/End (Ctrl for document), PageUp/Down; Shift extends the selection; Ctrl+A/C/X/V; Ctrl+Z, Ctrl+Y, Ctrl+Shift+Z; click and drag, double-click selects a word, triple-click a line; Alt+click or Ctrl+Alt+Up/Down adds cursors; Esc drops extra cursors.

Example: a save flow

fn save(self: *App) !void {
    const text = try self.editor.textAlloc(self.gpa);
    defer self.gpa.free(text);
    try std.Io.Dir.cwd().writeFile(self.io, .{ .sub_path = self.path, .data = text });
    self.editor.markSaved();
}

Not yet: find/replace, soft wrap, folding, bracket matching, IME preedit rendering.
