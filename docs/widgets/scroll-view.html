ScrollView

A clipped viewport onto content larger than the space available. It creates one child node, the content node; put your children there.

const scroll = try ui.add(zigui.ScrollView, parent, .{
    .style = .{ .grow = 1 },
    .content_style = .{ .direction = .column, .gap = .px(2), .padding = zigui.style.Edges.all(4) },
});
for (names) |n| _ = try ui.add(zigui.Label, scroll.contentNode(), .{ .text = n });

The content is laid out at its natural size along the scrolling axis and never shrunk. Scroll with the wheel (Shift+wheel for horizontal) or by dragging the scrollbar thumb.

Options

OptionDefaultMeaning
style.{}The viewport's layout (give it a size or .grow = 1).
content_stylecolumnLayout of the content node: direction, gap, padding, alignment.
vertical, horizontaltrue, falseWhich axes scroll.
scrollbartrueDraw the scrollbar.

Methods

  • contentNode() Handle
  • scrollTo(x, y), scrollBy(dx, dy): clamped to the content.
  • scrollIntoView(handle): scroll just enough to show a descendant.
  • overlay: a paint hook slot drawn over the content (the builder draws selection overlays there).

The offset lives on the node (node.scroll_x/scroll_y), so hit testing, painting, damage and absoluteRect of everything inside follow it.

Document

Children of a scroll_view node go into its content node.

.{ .type = "scroll_view", .style = .{ .height = 200 }, .children = .{ .{ .type = "label", .props = .{ .text = "row" } } } }
