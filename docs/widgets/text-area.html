TextArea

A multi-line text field: a bordered box holding several lines, with typing, selection, the clipboard, undo and scrolling. It is a CodeEditor underneath (no line numbers, no highlighting, the UI font), so it behaves like one. Use TextField for one line and CodeEditor for code.

const notes = try ui.add(zigui.TextArea, parent, .{
    .style = .{ .width = .fill, .height = .px(90) },
    .text = "first line\nsecond line",
    .on_change = .bind(&app, App.notesChanged),
});

fn notesChanged(self: *App, _: *zigui.event.Event) void {
    const text = self.notes.textAlloc(self.gpa) catch return;   // the content; you free it
    defer self.gpa.free(text);
}

Out and methods

out: changed / change_count, focused, line_count. Methods: textAlloc(gpa), setText(text) (does not call on_change), loadText(bytes, owned); the inner editor: *CodeEditor is available for anything else.

In forms and documents

A form uses a TextArea for any string whose ui metadata says .multiline = true (the builder's inspector does this for the titles, items, menus and options props, so you see and edit one entry per line). In a document the content is .props.text, as for a text field.

.{ .type = "text_area", .props = .{ .text = "line one\\nline two" }, .style = .{ .height = 120 } }
