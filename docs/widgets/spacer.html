Spacer

Empty space in a row or column. By default it is flexible: it grows into whatever room its siblings leave, so one pushes the widgets after it to the far end. With size it is a fixed gap of that many pixels along the parent's main axis (width in a row, height in a column).

_ = try ui.add(zigui.Button, bar, .{ .text = "File" });
_ = try ui.add(zigui.Spacer, bar, .{});                  // flexible
_ = try ui.add(zigui.Button, bar, .{ .text = "Help" });  // pinned to the right
_ = try ui.add(zigui.Spacer, bar, .{ .size = 12 });      // a 12px gap

Several flexible spacers share the free room equally (they have grow = 1 each); give one a different style.grow to weight it. In a grid a spacer is just an empty cell.

Options

OptionDefaultMeaning
style.{}Layout; with no size and no grow, it gets grow = 1.
size00 is flexible; otherwise the fixed length in pixels. Changing props.size later works, and a spacer follows its parent's direction if that changes.

Document

.{ .type = "spacer" }
.{ .type = "spacer", .props = .{ .size = 16 } }
