Canvas

A node you draw into and read raw input from: paint programs, viewports, custom widgets. Two drawing modes (usable together): a draw hook that emits draw-list commands, and an offscreen pixel surface.

Draw-hook mode

const c = try ui.add(zigui.Canvas, parent, .{
    .style = .{ .grow = 1 },
    .on_draw = zigui.canvas.DrawHook.bind(&app, App.draw),
});

fn draw(self: *App, canvas: *zigui.Canvas, pc: *zigui.PaintCtx) zigui.paint_ctx.Error!void {
    const paint = zigui.draw_list.Paint.solid(zigui.Color.rgb(255, 80, 80));
    try pc.list.fillRect(.{ .x = pc.rect.x + 10, .y = pc.rect.y + 10, .w = 80, .h = 40 }, paint);
}

pc.rect is the canvas rectangle in window coordinates; commands are clipped to it. Draw-list commands include fillRect, strokeRect, rounded variants, line, image, pushClip.

Offscreen surface mode

try canvas.createSurface(1024, 768);                       // after the backend exists
canvas.updateSurface(.{ .x = 0, .y = 0, .w = w, .h = h }, pixels, w * 4) catch {};   // RGBA8 rows, stride in bytes
...
canvas.releaseSurface();                                   // before destroying the canvas

The surface is stretched over the node (filter: .nearest or .linear). Convert pointer positions to surface pixels with canvas.toSurface(local_x, local_y). examples/paint.zig is a complete program.

Options

OptionDefaultMeaning
style.{}
label"Canvas"Accessible name.
redraw_policy.on_demand.on_demand (repaint on invalidate() or input), .continuous (every frame), .fixed_hz (hz per second).
hz30For .fixed_hz.
raw_keysfalseA focused canvas gets every key (Tab and shortcuts too); only Escape leaves it.
grab_inputfalseAll pointer input goes to the canvas wherever the pointer is.
filter.linearSurface scaling.
on_pointernullPointer enter/leave/down/move/up and wheel; use ev.local_x/local_y. A press captures the pointer until release.
on_keynullKey down/up and committed text.
on_drawnullThe draw hook.

Out

hovered, focused, pressed, pointer_x/pointer_y (canvas-local), frames (times painted).

Methods

  • invalidate(?Rect): request a repaint (null = all).
  • createSurface, updateSurface, releaseSurface, toSurface
For animation set redraw_policy = .continuous or .fixed_hz and use ui.nextWakeMs() in your loop so it wakes on time.
