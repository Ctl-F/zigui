Label

Non-interactive text with no box. Its size comes from the text.

const title = try ui.add(zigui.Label, parent, .{ .text = "Project", .size = 18 });
title.setText("Project: zigui");

Options

OptionDefaultMeaning
style.{}Layout.
text""Copied.
font.ui.ui or .mono (the theme's fonts).
size0Em size in logical pixels; 0 uses the theme's font_size.
colortransparentTransparent means the theme's text color.
text_align.start.start .center .end within the label's width.
painternullOverride the theme's label painter.
