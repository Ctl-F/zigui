TextField

A single-line text input: caret, selection, clipboard, IME, placeholder. Typing, Home/End, Ctrl/Alt+arrows for words, Shift to select, and Ctrl+A/C/X/V work. Not yet: undo/redo and password mode.

const name = try ui.add(zigui.TextField, parent, .{
    .placeholder = "Project name",
    .style = .{ .width = .px(240) },
    .on_change = .bind(&app, App.nameChanged),
    .on_submit = .bind(&app, App.create),
});

fn nameChanged(self: *App, _: *zigui.event.Event) void {
    self.project_name = self.name_field.text();    // valid until the next edit
}

Tab selects. Moving focus into a field with Tab (or Shift+Tab) selects its whole text, so you can type a new value immediately. Clicking a field places the caret as usual.

For several lines use TextArea.

Methods

  • text() []const u8: the content. The slice is invalidated by the next edit; copy it if you keep it.
  • setText(text) !void, setPlaceholder(text) !void, setPainter, colors()
setText does not fire on_change; that callback is for user edits.
