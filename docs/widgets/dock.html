Dock

Panels you can arrange. Panels sit in tabbed groups (TabPanel), groups sit in resizable splits (SplitView), and any panel — or a whole floating window — can be dragged somewhere else. Run zig build docking to try it.

const dock = try zigui.Dock.create(&ui, parent, .{ .style = .{ .width = .fill, .height = .fill } });
defer dock.destroy();

const files = try dock.addPanel("Files");     // hidden until docked; files.content is yours to fill
const editor = try dock.addPanel("Editor");
_ = try ui.add(zigui.TreeView, files.content, .{ .style = .{ .grow = 1 } });

try dock.dockTab(editor, null);                // into the first group
try dock.dockSplit(files, editor, .left, 220); // a 220px column to the left of Editor

Dragging

Do thisResult
Drag a tab along its own barReorders the tabs.
Drop it on another group's tab bar or middleIt becomes a tab there (at the pointer's position on the bar).
Drop it near a group's left, right, top or bottom edgeThe group splits and the panel gets the new half (a blue preview shows where).
Hold Shift while dropping, or drop outside the dockThe panel floats in a window of its own where it was dropped.
Drag a floating window's title strip onto a groupAll its tabs dock there (tab or split, as above).
Drag the grip at a floating window's cornerResize it.
Right-click a tabFloat (or Dock) / Close.
Click a tab's ×Closes the panel: it is hidden, not destroyed, and keeps its state. showPanel brings it back where it was.

A group that loses its last panel disappears and its split collapses.

API

CallPurpose
Dock.create(ui, parent, .{ .style }), destroy()The dock is a heap object; dock.host is its node.
addPanel(title) !*PanelA new hidden panel. panel.content is its content node, panel.state is .hidden, .docked or .floating, panel.user is yours.
dockTab(panel, near)Tab into near's group, or the first group (creating the root group if the dock is empty).
dockSplit(panel, near, side, size)A new group beside near's: side is .left .right .top .bottom, size its pixels along the split.
floatPanel(panel, rect)Float it at rect (relative to the dock).
closePanel(panel), showPanel(panel), destroyPanel(panel)Hide, restore, or remove for good (destroying its content).
panelNamed(title), rebuild()Lookup; rebuild the widgets from the model (done after every change).

How it works

The layout is a model (groups, splits, floating windows) that the dock turns into TabPanels and SplitViews. After each change it detaches every panel's content, rebuilds the widgets and re-parents the content into its new page, so a panel keeps its widgets, text and scroll state when it moves. Split sizes are remembered across rebuilds.

Limits

  • Floating windows live inside the dock's window; they cannot leave the application window yet (that needs multi-window support in the platform layer).
  • The layout is not saved and restored yet.
  • Tabs only on top; no auto-hide sidebars.
