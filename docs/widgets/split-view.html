SplitView

Two panes separated by a draggable divider. The first pane is first_size pixels along the split axis; the second takes the rest. Dragging the divider changes first_size within the minimums. The resize cursor shows over the divider.

const split = try ui.add(zigui.SplitView, parent, .{
    .style = .{ .grow = 1 },
    .first_size = 260,
});
_ = try ui.add(zigui.Label, split.firstNode(), .{ .text = "Files" });
_ = try ui.add(zigui.CodeEditor, split.secondNode(), .{ .style = .{ .grow = 1 } });

The pane nodes are columns. To make content fill a pane, give it .width = .fill and .height = .fill (or .grow = 1).

Options

OptionDefaultMeaning
style.{}Layout of the whole split. Give it a size: .fill/.grow = 1, or a fixed height.
verticalfalsefalse: panes side by side; true: stacked.
first_size240Size of the first pane in pixels.
min_first, min_second48Minimum pane sizes.
divider_size6

Document

A split_view has two children: child 0 is the first pane, child 1 the second.

.{ .type = "split_view", .props = .{ .first_size = 200 }, .style = .{ .width = .fill, .height = .fill },
   .children = .{ .{ .type = "box" }, .{ .type = "box" } } }
