Popup

A small overlay that does not take keyboard focus: a suggestion list that follows typing, or a tooltip or signature hint. The widget that opens it keeps receiving keys; it moves the selection and picks through the Ui. (Menus, by contrast, hold focus while open; see menus.)

try ui.showPopup(&.{
    .{ .tag = "fn", .label = "print", .detail = "(fmt, args) void" },
    .{ .tag = "fn", .label = "printErr" },
}, .{ .anchor = caret_rect, .on_pick = zigui.menu.PickHook.bind(&app, App.onPick) });

ui.popupMove(1);          // Down
_ = ui.popupPick();       // Enter / Tab: closes, then calls on_pick(index)
ui.hidePopup();           // Escape

// A hint over the line, with part of its first line emphasized (the active parameter):
try ui.showTipOpts("@Vector(len: comptime_int, Element: type) type", caret_rect,
    .{ .above = true, .mark_start = 27, .mark_end = 39 });
ui.hideTip();

try ui.showTip("Returns the length.\nO(1)", anchor_rect);   // a tooltip, one label per line

Behavior

  • Two slots: a list (ui.popup) and a tip (ui.tip: a tooltip or a signature hint). Opening one replaces only the same kind, so a suggestion list and a signature hint can be open together.
  • It opens below anchor (window coordinates), above if there is no room, and stays inside the window.
  • A list closes when the pointer is pressed outside it; the press still reaches whatever is underneath. Clicking a row picks it without moving focus away from the editor.
  • A tooltip ignores the pointer completely and has no selection.
  • Rows are copied, so the slice only needs to live for the call. More than max_rows (10) rows scroll.

API

  • Row: label, detail (dimmed, after the label), tag (dimmed, before it), user.
  • Options: anchor, kind (.list or .tip), on_pick, max_rows, min_width, selected.
  • Ui.showPopup(rows, opts), showTip(text, anchor), showTipOpts(text, anchor, .{above, mark_start, mark_end}), hideTip(), tipOpen(), hidePopup(), popupOpen(), popupMove(delta) (wraps), popupPick() bool.
  • ui.popup (the open Popup, or null): count(), selectedIndex(), selectIndex(i), userOf(i).

Code-only (not a toolbox widget). Completion is built on it.
