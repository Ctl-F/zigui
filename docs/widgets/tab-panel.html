TabPanel

A row of tabs over a stack of pages; only the active page shows. Each tab owns a page node that you fill like any container.

const tabs = try ui.add(zigui.TabPanel, parent, .{ .style = .{ .width = .fill, .height = .fill } });
const files = try tabs.addTab("Files");              // the page node for that tab
_ = try ui.add(zigui.Label, files, .{ .text = "..." });
const search = try tabs.addTab("Search");
tabs.setActive(1);

Click a tab, or focus one and use Left/Right (they wrap), to switch. Drag a tab along the bar to reorder it. With closable each tab has an ×.

Options

OptionDefaultMeaning
style.{}Layout of the whole panel (give it a size).
titles&.{}Tab titles (copied); each gets a page.
active0The shown tab.
closablefalseA close button on each tab.
close_removestrueClosing removes the tab and its page. Turn off to only get on_close (the dock does, to hide panels instead).
on_changenullThe user switched tabs (setActive does not call it).
on_closenullA close button was pressed; out.closed_index says which.
drag_hooknullA DragHook told when a tab drag begins, moves, and ends (with the pointer position), so a host can tear tabs out. Reordering along the bar happens anyway.

Methods

MethodPurpose
addTab(title) !HandleAdd a tab at the end; returns its page node.
removeTab(i), moveTab(from, to), setTitle(i, title)Edit the tabs. Titles live in props.titles, one per line.
adoptTab(title, index, node) !void, releaseTab(i) ?HandleMove a node between panels: releaseTab takes the page's content out (removing the tab), adoptTab puts a node into a new page. This is how the dock moves panels.
pageNode(i), tabCount(), title(i), activeTab(), setActive(i)Queries.
tabRect(i), barRect(), tabAt(x, y)Geometry in window coordinates.

Document

A tab_view's children are its pages, in order; titles names them. The builder adds one with two box pages, and selecting a node on a hidden page brings its tab forward.

.{ .type = "tab_view", .props = .{ .titles = "General\nAdvanced" }, .style = .{ .width = .fill, .height = .fill },
   .children = .{ .{ .type = "box" }, .{ .type = "box" } } }

Limits

Tabs do not scroll or wrap when there are more than fit the width; tabs are on top only.
