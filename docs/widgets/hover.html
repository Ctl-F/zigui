Hover and signature help

Two small overlays that explain code, both for a CodeEditor and both drawn as a tooltip (see Popup).

  • Hover: rest the pointer on an identifier for about 450 ms and a tooltip shows what providers know about it (a declaration and its doc comment). It goes away when the pointer moves to another word, leaves the editor, or you press a key, click or scroll.
  • Signature help: while the caret is inside the parentheses of a call, a hint above the line shows the callee's parameter list with the parameter you are typing emphasized, for example @Vector(len: comptime_int, Element: type) type. It opens when you type, follows the caret (arrows, Backspace) and the comma count, and closes when the caret leaves the call or on Escape. It stays open while a suggestion list is showing.
const hover = try zigui.hover.Hover.create(&ui);
try hover.addProvider(.bind(&mine, Mine.hover));          // fn (*Mine, *const HoverRequest, *Lines) void
try hover.attach(editor);

const sig = try zigui.hover.SignatureHelp.create(&ui);
try sig.addProvider(.bind(&mine, Mine.signature));        // fn (*Mine, *const SigRequest, *SigSink) void
try sig.attach(editor);
// before destroying an editor: hover.detach(editor); sig.detach(editor);

Providers

Providers run on the UI thread and must answer from what they already know (an index, a language server's cached reply).

  • HoverRequest: editor, word (with a leading @ if it has one), word_start, line_before. Add lines with Lines.add(text) (copied; long lines wrap at 88 columns). No lines means no tooltip. hover.delay_ms sets the wait.
  • SigRequest: editor, callee (@Vector, std.mem.eql), active (0-based argument index). Answer with SigSink.set(text, params) where params are the byte ranges of each parameter within text; the first provider that answers wins.
  • hover.enclosingCall(text_before_caret) is the scanner both use: it returns the callee and argument index, skipping if (, grouping parentheses, fn name( declarations and commas inside [ ]/{ }.

The IDE's Zig provider (ide.zig_complete.ZigCompleter: hoverProvider(), signatureProvider()) shows declarations from the standard library and your files (with their /// doc comments) and the builtin functions; see the IDE page. Code-only (not a toolbox widget).
