Button

A clickable button with hover, pressed, focus, and disabled states. Enter and Space activate it when focused.

const save = try ui.add(zigui.Button, parent, .{
    .text = "Save",
    .variant = .primary,
    .on_click = .bind(&app, App.save),
});

Options

OptionDefaultMeaning
style.{}Layout. With no padding set the theme's button_padding applies.
text""Label, copied.
variant.normal.normal .primary .danger .flat: which color set from the theme.
enabledtrueA disabled button ignores clicks and is skipped by Tab.
text_align.centerLabel alignment.
on_clicknullCallback; runs for pointer clicks and keyboard activation.
commandnullName of a command to run instead. The button is enabled only while the command is.
colorsnullOverride the theme's ButtonColors for this button.
painternullOverride the theme's button painter.

Out

FieldMeaning
clickedClicked this frame (cleared by ui.endFrame()).
click_countTotal clicks since creation.
hovered, pressed, focused, focus_visibleCurrent state.

Methods

  • setText, setEnabled, setVariant, setPainter, setCommand(name)
  • colors(): the colors currently in effect.

Examples

A button tied to a command (shared with a shortcut)

_ = try ui.registerCommand("file.save", .{ .title = "Save", .run = .bind(&app, App.save) });
try ui.bindShortcut("mod+s", "file.save", .app, null);
_ = try ui.add(zigui.Button, toolbar, .{ .text = "Save", .command = "file.save" });

A colored swatch button

b.props.colors = .{ .normal = c, .hover = c, .pressed = c, .disabled = c, .border = zigui.Color.white, .border_width = 1 };

Document

.{ .type = "button", .id = "ok", .props = .{ .text = "OK", .variant = .primary }, .on = .{ .click = "confirm" } }
