MessageBox

A modal message box: a title, a few lines of text and up to four buttons, for a question the program must ask before going on (“Install it now?”).

const mb = try zigui.message_box.MessageBox.create(&ui, ui.tree.root);   // hidden until shown
defer mb.destroy();
mb.show(.{
    .title = "ZVM not found",
    .message = "ZVM is not installed.\nInstall it now?",     // \n starts a new line (up to 10, not wrapped)
    .buttons = &.{ "Install", "Not now", "Never" },          // up to 4; the first is the default
    .cancel = 1,                                             // what Escape chooses (default: the last)
    .on_choice = .bind(&app, App.chose),                     // fn (*App, index: usize) void
});

The hook runs after the box closed and gets the button's index. While it is open it holds a modal focus scope: the rest of the window gets no input, and clicks on the dimmed area do nothing. choose(index) and close() drive it from code; isOpen() says whether it is showing. Code-only widget.
