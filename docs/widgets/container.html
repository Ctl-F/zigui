Containers (box)

A plain container is a node with no widget: a Style that arranges its children and an optional Visual background. In UI documents its type name is "box".

const panel = try ui.tree.create(.{
    .style = .{ .direction = .column, .gap = .px(6), .padding = zigui.style.Edges.all(8) },
    .visual = .{ .background = zigui.Color.rgb(34, 36, 41), .border_width = 1,
                 .border_color = zigui.Color.rgb(64, 68, 76), .radius = 4 },
});
try ui.tree.appendChild(parent, panel);
_ = try ui.add(zigui.Label, panel, .{ .text = "Inside the panel" });

Useful node fields

FieldMeaning
styleLayout, see Layout.
visualBackground, border, corner radius.
flags.clip_childrenClip children to the node's rectangle when painting.
role, labelAccessibility; set the label with ui.tree.setLabel.
cursorMouse cursor shape over the node.
user_dataAn opaque pointer for your own bookkeeping.

Tree operations

try ui.tree.appendChild(parent, child);
_ = ui.tree.destroySubtree(node);       // children included; widgets are cleaned up
ui.setHidden(node, true);               // takes no space while hidden

.{ .type = "box", .style = .{ .direction = .column, .gap = 6 }, .children = .{ ... } }
