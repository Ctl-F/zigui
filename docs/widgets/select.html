Select

A drop-down list. It shows the chosen option; clicking it (or Enter, Space, Up, Down when focused) opens a menu of the options below it, or above it when there is no room. Choosing one closes the menu and fires on_change. Clicking the select again while its menu is open closes it.

const align_pick = try ui.add(zigui.Select, parent, .{
    .items = &.{ "start", "center", "end", "stretch" },
    .selected = 3,
    .on_change = .bind(&app, App.onAlign),
});

fn onAlign(self: *App, _: *zigui.event.Event) void {
    self.align_value = self.align_pick.props.selected;   // 0-based index
}

Options

OptionDefaultMeaning
style.{}Layout. With no padding set the theme's field_padding applies, with extra room on the right for the arrow. Give it a width or .grow = 1.
items&.{}The options (copied).
selected0Index of the chosen option.
enabledtrueA disabled select cannot be opened or focused.

painternullOverride theme.select_painter.

Props and Out

props.options holds the options as one text, one per line, so the registry, documents and the builder can edit them like any text; props.selected is the index. out: changed / change_count (the user chose something), open (its menu is showing), hovered, focused, focus_visible.

Methods

  • setItems(items) !void, setOptionsText(text) !void: replace the options. The selection index is kept (it may then point past the end).
  • setSelected(index): choose an option programmatically; fires on_change only if it changed.
  • count(), itemLabel(i), selectedLabel(), openMenu(), setPainter(...)

Document

.{ .type = "select", .props = .{ .options = "small\nmedium\nlarge", .selected = 1 } }

Limits

No type-ahead search, no scrolling for lists taller than the window, one line per option.
