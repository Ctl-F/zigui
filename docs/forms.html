Forms and wizards

Generate a dialog body from a Zig struct. The form is built from the struct's runtime schema, so you describe the data and get the controls.

const NewProject = struct {
    name: []const u8 = "",
    kind: enum { app, library } = .app,
    shared: bool = false,
    count: u32 = 1,

    pub const ui = .{                       // optional metadata
        .count = .{ .label = "How many", .min = 1, .max = 9 },
    };
    pub fn validate(self: *const NewProject, report: *zigui.form.Report) void {   // optional cross-field checks
        if (self.name.len == 0) report.add("name", "Name is required");
    }
};

var form = try zigui.form.Form(NewProject).create(&ui, parent, .{ .title = "New project" });
defer form.destroy();

// each frame:
if (form.state == .submitted) {
    const value = try form.take(gpa);       // deep copy
    defer zigui.form.freeOwned(NewProject, value, gpa);   // or take(arena) and skip freeing
    ...
}
Field typeControl
boolOn/Off toggle
enumSelect drop-down of the names (binding.select)
strings with .multiline = true in their ui metadataTextArea (binding.area)
numbers, colors, Lengths, other stringsText fields with parsing; errors show under the field and disable Submit
optionalA "Set" toggle plus the control
struct, arrayIndented group

Metadata keys in pub const ui: label, tooltip, min, max, step, group, multiline, hidden, readonly. Form options: title, submit_label, cancel_label, style, label_width, only (list of fields), group. form.state is .open, .submitted, or .cancelled. The form is non-blocking; a blocking prompt is not built yet.

Wizards

zigui.wizard.Wizard(T) is a list of pages over one result struct with Back/Next/Finish/Cancel and a step indicator. A page is generated (.fields = &.{"name", "kind"} or .group = "advanced") or custom (a build callback that fills a host node). can_next and page-scoped validation gate Next; values persist across pages.

const pages = [_]Wizard(NewProject).Page{
    .{ .title = "Basics", .fields = &.{ "name", "kind" } },
    .{ .title = "Options", .fields = &.{ "shared", "count" } },
};
const wiz = try Wizard(NewProject).create(&ui, parent, &pages, .{ .title = "New project" });
// each frame: wiz.state == .submitted / .cancelled
