Layout and styling

Every node has a Style. Layout is a two-pass flexbox-like model: children are measured bottom-up, then placed top-down. A node arranges its children along a main axis (direction).

Style fields

FieldDefaultMeaning
width, height.autoPreferred size, a Length.
min_width, max_width, min_height, max_height.auto (unbounded)Clamp the resolved size. If min exceeds max, min wins.
grow0Share of leftover main-axis space this child takes.
shrink1Share of overflow this child gives up. Use 0 for things that must not shrink (toolbars, fixed headers).
direction.row.row or .column: the main axis of this node's children.
gap0Space between children.
padding, margin0Edges: .left/.top/.right/.bottom as Lengths. Build with Edges.all(8) or Edges.xy(12, 4).
align_items.stretchCross-axis alignment of children: .start .center .end .stretch.
justify.startMain-axis placement when nothing grows: .start .center .end.
align_selfnullOverrides the parent's align_items for this child.
wrapfalseContinue on a new line when children overflow the main axis.
position, inset.flowAbsolute positioning, see below.
grid_columns0Non-zero makes this node a grid with that many equal columns.
grid_span1For a child of a grid: how many columns it spans.

Edges lives in zigui.style: const Edges = zigui.style.Edges;

Length

ValueMeaning
.px(120)Logical pixels.
.pct(50)Percent of the parent's content box on that axis. Falls back to auto if the parent is itself sized by its content (and counts a ui_check warning).
.autoSize to content, then flex rules (grow/shrink) apply.
.fillTake the remaining space (basis 0, grow at least 1).
.fitShrink-wrap the children, clamped by min/max.

Sizes are resolved first and then clamped to min/max in absolute terms.

Examples

A toolbar, a growing content area, a status bar

(box(parent, style) stands for tree.create(.{ .style = style }) followed by tree.appendChild.)

root.style = .{ .direction = .column };
// header: fixed height, does not shrink
const header = try box(root, .{ .direction = .row, .height = .px(40), .shrink = 0, .gap = .px(8), .align_items = .center });
// body: takes everything left over
const body = try box(root, .{ .direction = .row, .grow = 1 });
const status = try box(root, .{ .height = .px(24), .shrink = 0 });

A sidebar that is 20% wide, at least 150 and at most 360 pixels

.{ .width = .pct(20), .min_width = .px(150), .max_width = .px(360), .shrink = 0 }

Centering one child

container.style = .{ .align_items = .center, .justify = .center };

Wrapping a row of chips

chips.style = .{ .direction = .row, .wrap = true, .gap = .px(4), .width = .px(300) };
Wrap needs a definite main-axis size (a fixed width, a parent that gives one, or .fill). A wrapping container does not yet grow to hold the extra lines when its own size is content-driven; give it an explicit height or let its parent size it.

Grid layout

Set grid_columns on a container and its children fill rows of that many equal-width columns, left to right then top to bottom. Each row is as tall as its tallest cell. gap is used between rows and between columns.

// a two-column toolbox
const grid = try tree.create(.{ .style = .{ .grid_columns = 2, .gap = .px(4) } });
try tree.appendChild(parent, grid);
for (names) |n| _ = try ui.add(zigui.Button, grid, .{ .text = n });
  • Column width is (content width - gaps) / columns. The grid needs a definite width (a fixed width, .fill, or a stretching parent). A .fit grid sizes its columns to the widest cell.
  • A child with .width = .auto fills its cell when align_items is .stretch (the default); with .start/.center/.end it keeps its natural width and is placed accordingly. A fixed width or height is honored. align_self overrides per child. Margins are respected inside the cell.
  • grid_span = 2 makes a child cover two columns; a child that does not fit the rest of the row starts a new row. Spans larger than the column count are clamped.
  • Hidden and absolute children take no cell.
  • Not yet: per-column sizes (fixed/fractional tracks), explicit row/column placement, auto-fit column counts, row spans.

Absolute positioning

A child with position = .absolute leaves the flex flow and is placed relative to its parent's box (padding included) using inset (.left .top .right .bottom, each a Length, .auto when unset). With both left and right (or top and bottom) set and the size .auto, the child stretches between them; otherwise it sits at the offset from the near side given, or from the far side if only that one is set. With no inset on an axis it starts at the parent's padding edge.

badge.style = .{ .position = .absolute, .width = .px(18), .height = .px(18),
                 .inset = .{ .right = .px(4), .top = .px(4) } };

Absolute children are ignored when the parent computes its content size.

Visual

node.visual is the stopgap look for a plain node: background, border_color, border_width, radius. Widgets paint themselves through the theme; see Theming.

node.visual = .{ .background = zigui.Color.rgb(44, 46, 52), .border_color = zigui.Color.rgb(64, 68, 76), .border_width = 1, .radius = 4 };

Changing style at runtime

After editing node.style tell the toolkit what changed:

ui.tree.get(h).?.style.width = .px(300);
ui.tree.markDirty(h, zigui.DirtyFlags.layout_and_paint);

Hide and show with ui.setHidden(h, true); a hidden node takes no space.
