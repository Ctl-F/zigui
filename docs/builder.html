The builder

A visual editor for UI documents, written with the toolkit itself. Run it with zig build builder (edits ./ui.zon) or zig-out/bin/builder FILE.zon. zig build workbench shows the document text in a CodeEditor next to the builder, synced both ways.

The screen

  • Add palette (left, top; a two-column grid): click to add the widget inside the selected box (or after the selected widget); drag onto the preview or outline to place it exactly.
  • Outline (left, bottom): the document as a TreeView. Click to select, click an arrow to collapse or expand (your choices survive edits), use the arrow keys to move, drag a row to reorder or reparent.
  • Preview (center): the UI, not running. Click to select (empty frame space selects the root); hover and selection are drawn as overlays. Drag to move; drag the right, bottom, or corner handles to set pixel width and height. Frame presets (Fill, 360x640, 800x600, 1280x720) show device sizes.
  • Inspector (right): the node's title and id, then four sections that are real tabs of a dock of their own — Props and Style (generated from the widget schemas), Layout (direction, gap, padding, align, justify, wrap, width/height modes, grow, shrink, margin, position and insets, grid columns on containers, and grid span on children of a grid), and Events (bind events to actions). Drag a section's tab to the edge of the inspector to stack it with another (Props above Layout, say), or float it; right-click a tab to float or close it. All sections stay up to date, and the View menu lists them under a separator to bring a closed one back.
  • Toolbar: Undo, Redo, Duplicate, Wrap in box, Unwrap, Indent, Outdent, Up, Down, Delete, Cut, Copy, Paste (as ZON text through the system clipboard), Save.

Menus, right-click, rename

  • An application menu bar (File, Edit, Structure) runs the same commands as the toolbar; items grey out when the command is unavailable and show their shortcuts.
  • Right-click a node in the preview or the outline to select it and open a context menu (cut, copy, paste, duplicate, delete, wrap, unwrap, indent, outdent, move, rename).
  • Rename: double-click an outline row (or press F2, or use the menu) to edit the node's id in place. Enter or clicking away applies it, Escape cancels. It is one undo step.
  • Widget actions: the context menu ends with a submenu named for the widget (for example split_view) of that widget's own commands: a split view can switch between horizontal and vertical or anchor its second pane, a scroll view can scroll horizontally or hide its scrollbar, a code editor can toggle line numbers or read-only. They flip a prop and are recorded as one undo step. Widgets declare these with pub const actions (see Maintaining these docs).
  • Layout mode: a container's Layout tab has a layout drop-down: row, column, or grid. Choosing grid sets two columns and shows a "grid columns" field; children of a grid get a "grid span" field. A scroll view's content grid is its content_columns prop.
  • Multi-select: Ctrl-click (or Shift-click) in the outline or Ctrl/Shift-click in the preview adds nodes to the selection (up to 32); a plain click selects one again. The inspector title shows "+ N more" and the Layout tab's choices and fields apply to every selected node. Delete and Duplicate act on all of them as one undo step (a selected node inside another selected node is covered by its parent). Copy, cut and paste work on the whole selection (pasting several nodes at once), and Move up/down and Wrap in box work when the selected nodes share a parent (wrap puts them into one new box). Unwrap, indent, outdent and rename need a single selection, so they are greyed out; the Props and Style tabs edit the primary node only.
  • Edit text in place: double-click a button or label in the preview to type its text over it; Enter or clicking away applies it (one undo step), Escape cancels.
  • Drop-downs: the Layout tab's choices (direction, align, justify, wrap, size modes, position) and enum props are Select drop-downs.

Dockable panels

The builder's four regions — Toolbox, Outline, Preview and Inspector — are Dock panels. Drag a tab onto another group to tab it in, onto an edge to split, hold Shift or drop it outside to float it; right-click a tab to float or close it. The View menu brings back a panel you closed. Builder.create(..., .{ .dock = my_dock }) puts the panels in your own dock (then call builder.arrange() for the default layout); without it the builder makes its own. The workbench does this so the document text is a fifth panel in the same dock.

The toolbox lists every registered widget (all of those on the widgets page with a document name, plus box); it scrolls when the panel is small. New tree_view, menu_bar, tab_view and dock nodes start with sample content.

Resizable regions

Dock panels are separated by SplitView dividers: drag them to resize. In the preview, drag a split_view's own divider to set its first_size (recorded as one undo step) instead of typing the number.

Defaults for new nodes

Area widgets added from the palette (box, scroll_view, split_view, code_editor, canvas) start with .width = .fill, .height = .fill, and a split view's two panes are boxes that fill their halves. Change them in the Layout tab.

Shortcuts

Active while focus is in the preview panel: Ctrl+Z, Ctrl+Shift+Z / Ctrl+Y, Ctrl+S, Ctrl+D (duplicate), Ctrl+C/X/V, Ctrl+G (wrap), Ctrl+Shift+G (unwrap), Delete, Alt+Up/Down (move), Alt+Right (indent), Alt+Left (outdent), F2 (rename).

Absolute positioning in the builder

Set a child's position to absolute in the Layout tab; it can then be dragged freely inside its parent and its insets are written for you.

The preview's root fills the preview frame (it grows to fill unless the document sets grow), so fill heights inside the root behave as they would in a window.

Embedding the builder in your program

var doc = try zigui.uidoc.Doc.init(gpa);            // or parseDoc(...)
const builder = try zigui.builder.Builder.create(&ui, parent, doc, .{
    .save = .{ .ctx = &saver, .call = Saver.write },    // called with the ZON text on Save
    .on_change = .bind(&app, App.docChanged),
    .command_prefix = "builder",                       // give each builder its own prefix
});
defer builder.destroy();

builder.modified();                  // unsaved changes?
builder.markSaved();
const text = try builder.toZon(gpa); // current document as ZON; free it
try builder.loadDocument(new_doc);   // swap the document

examples/workbench.zig shows a complete embedding with a text pane.

Limits

No zoom, no live text editing on the preview, no drag from the preview onto the inspector.
