The builder

A visual editor for UI documents, written with the toolkit itself. Run it with zig build builder (edits ./ui.zon) or zig-out/bin/builder FILE.zon. zig build workbench shows the document text in a CodeEditor next to the builder, synced both ways.

The screen

  • Add palette (left, top): click to add the widget inside the selected box (or after the selected widget); drag onto the preview or outline to place it exactly.
  • Outline (left, bottom): the document tree. Click to select; drag to reorder or reparent.
  • Preview (center): the UI, not running. Click to select (empty frame space selects the root); hover and selection are drawn as overlays. Drag to move; drag the right, bottom, or corner handles to set pixel width and height. Frame presets (Fill, 360x640, 800x600, 1280x720) show device sizes.
  • Inspector (right): tabs for props and style (generated from the widget schemas), layout (direction, gap, padding, align, justify, wrap, width/height modes, grow, shrink, margin, position and insets), and events (bind events to actions).
  • Toolbar: Undo, Redo, Duplicate, Wrap in box, Unwrap, Indent, Outdent, Up, Down, Delete, Cut, Copy, Paste (as ZON text through the system clipboard), Save.

Shortcuts

Active while focus is in the preview panel: Ctrl+Z, Ctrl+Shift+Z / Ctrl+Y, Ctrl+S, Ctrl+D (duplicate), Ctrl+C/X/V, Ctrl+G (wrap), Ctrl+Shift+G (unwrap), Delete, Alt+Up/Down (move), Alt+Right (indent), Alt+Left (outdent).

Absolute positioning in the builder

Set a child's position to absolute in the Layout tab; it can then be dragged freely inside its parent and its insets are written for you.

The preview's root fills the preview frame (it grows to fill unless the document sets grow), so fill heights inside the root behave as they would in a window.

Embedding the builder in your program

var doc = try zigui.uidoc.Doc.init(gpa);            // or parseDoc(...)
const builder = try zigui.builder.Builder.create(&ui, parent, doc, .{
    .save = .{ .ctx = &saver, .call = Saver.write },    // called with the ZON text on Save
    .on_change = .bind(&app, App.docChanged),
    .command_prefix = "builder",                       // give each builder its own prefix
});
defer builder.destroy();

builder.modified();                  // unsaved changes?
builder.markSaved();
const text = try builder.toZon(gpa); // current document as ZON; free it
try builder.loadDocument(new_doc);   // swap the document

examples/workbench.zig shows a complete embedding with a text pane.

Limits

No multi-selection, no zoom, no live text editing on the preview, no drag from the preview onto the inspector; enum values are cycle buttons.
